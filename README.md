# Permitopolis Events Permitting

A clickable, front-end-only prototype of a city clerk's event permitting site: a public landing page,
an applicant wizard and to-do board, and queue, pipeline and case views for three city roles. All
state lives in the browser and resets to a seed of 38 cases on a fixed demo date, Mon, May 3, 2027.

## Run it

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm check      # type-check, lint, tests, build
```
